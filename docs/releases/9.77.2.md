# ADAAD 9.77.2 Release Notes — Governance Runtime Profile Schema Extension

**Release date:** 2026-04-15  
**Baseline:** v9.77.1

---

## Summary

This patch adds schema-backed support for new top-level runtime profile metadata
with a backward-compatible migration path.

## What changed

- Added `schemas/governance_runtime_profile.lock.v1.json` as the canonical schema
  for `governance_runtime_profile.lock.json`.
- Added optional `agents` top-level section with `grok-integrator` metadata.
- Updated preflight runtime profile validation to:
  - run schema validation before enforcement checks,
  - apply deterministic in-memory migration for legacy lock files missing `agents`,
  - fail closed on invalid `agents` payloads.
- Updated governance schema validator coverage and `scripts/validate_governance_schemas.py`
  to include runtime profile lock schema/payload validation.
- Added backward-compatibility tests for existing lock files that do not yet include
  the new top-level section.

## Consumer guidance

- Profile consumers should treat `agents.grok-integrator` as optional metadata.
- When `enabled` is `false`, metadata is informational only and must not alter
  governance enforcement semantics.
- Existing lock files remain valid through deterministic migration in preflight.
