# Release Notes — v9.17.1

**Date:** 2026-04-22
**Type:** Patch

## Summary

- Clarified `ParetoCompetitionOrchestrator.run_epoch()` gate verdict semantics to
  use explicit, reachable states only: `"pass"` and `"fail"`.
- Removed the unreachable ternary branch that implied `"deferred"` could be
  emitted in this path.
- Added regression tests to confirm:
  - `"pass"` remains the success verdict.
  - `"fail"` is recorded in ledger payloads when all frontier candidates fail.
  - Unsupported gate outputs (e.g. `"deferred"`) are rejected explicitly.
