# DORK EVOLUTIONARY ROADMAP (Phases 127–132)

This roadmap defines the implementation of the **DORK Governance Intelligence Layer**. These phases run sequentially following the Phase 126 "Break It" Challenge.

---

### PHASE 127 — GENESIS & DATA INTEGRITY
**Focus:** Establishing the immutable records and monitoring the infrastructure that houses them.
*   **DORK-PERM-001 (CLE):** Constitutional Lineage Engine. (Genesis mapping).
*   **DORK-PERM-018 (LHGO):** Ledger Health and Growth Observatory. (Ensuring the `/data` directory is healthy).
*   **DORK-PERM-005 (DFL):** Determinism Fidelity Ledger. (Longitudinal seeding/replay tracking).
*   **DORK-PERM-021 (ALM):** **Audit Log Manifest.** A root-level indexing ledger that maps every other ledger’s location, schema, and HMAC status.

### PHASE 128 — THE LIVING FLEET (OBSERVABILITY)
**Focus:** Measuring the health of the innovation modules currently active in the system.
*   **DORK-PERM-002 (IET):** Invariant Evolution Tracker. (Hard/Soft invariant time-series).
*   **DORK-PERM-006 (IFGS):** Innovation Fitness Grading System. (Multi-dimensional module scoring).
*   **DORK-PERM-015 (SIPH):** Security Invariant Pressure Heatmap. (Hardening prioritization).
*   **DORK-PERM-022 (VEM):** **Validation Engine Monitor.** Real-time tracking of `pytest` coverage vs. invariant density per module.

### PHASE 129 — BEHAVIORAL INTELLIGENCE
**Focus:** Modeling the agents (and the human) that interact with the constitution.
*   **DORK-PERM-003 (ABFE):** Agent Behavior Fingerprint Engine. (Detecting agent drift).
*   **DORK-PERM-012 (AARE):** Adaptive Advisory Rule Engine. (Evolving the non-binding guidance).
*   **DORK-PERM-014 (KCE):** Knowledge Crystallization Engine. (Distilling architectural decisions).
*   **DORK-PERM-017 (CSPAD):** Cross-Session Pattern Anomaly Detector. (HUMAN-0 behavioral baseline).

### PHASE 130 — STRUCTURAL MECHANICS (PRESSURE)
**Focus:** Quantifying the "stress" on the system's logical foundations.
*   **DORK-PERM-007 (CPI):** Constitutional Pressure Index. (Finding the load-bearing clauses).
*   **DORK-PERM-004 (MEM):** Mutation Entropy Monitor. (Measuring exploration vs. stagnation).
*   **DORK-PERM-016 (PCTM):** Phase Complexity Trajectory Model. (Sustainability vs. bloat).

### PHASE 131 — PRE-MUTATION ASSURANCE (SAFETY)
**Focus:** Advanced tooling to prevent failures before they are committed to a branch.
*   **DORK-PERM-013 (MBRC):** Mutation Blast Radius Calculator. (Dependency/Invariant impact prediction).
*   **DORK-PERM-011 (ICDE):** Invariant Conflict Detection Engine. (Logical consistency check).
*   **DORK-PERM-009 (RARO):** Replay Archive and Regression Oracle. (Longitudinal regression detection).

### PHASE 132 — THE SOVEREIGN LAYER (CONSOLIDATION)
**Focus:** Rolling all signals into a single unified governance view.
*   **DORK-PERM-008 (GDAT):** Governance Debt Accumulation Tracker. (Deferred action penalty).
*   **DORK-PERM-010 (MDFS):** Multi-Dimensional Fitness Surface. (The radar chart of system health).
*   **DORK-PERM-019 (CSI):** Constitutional Strength Index. (The "one number" for ADAAD health).
*   **DORK-PERM-020 (EBS):** Emergent Behavior Sentinel. (Identifying the "Unknown Unknowns").
