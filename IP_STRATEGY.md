## Patent candidate families

The highest-value patent-review candidates are the repeated governed-autonomy patterns that combine deterministic execution, cryptographic auditability, and non-delegatable HUMAN-0 oversight:

1. **Constitutionally governed autonomous mutation lifecycle** — CEL admission, adversarial review, mutation queues, orchestration, execution, telemetry, and rollback under fail-closed invariant gates.
2. **Cryptographically chained governance evidence systems** — lineage ledgers, cross-ledger integrity, artifact provenance, meta-ledger aggregation, invariant lineage, and portable proof bundles.
3. **Autonomous constitutional self-improvement under human ratification** — amendment generation, simulation, delivery, disposition learning, execution, monitoring, and rollback while preserving HUMAN-0 authority.
4. **Governed local-LLM knowledge and retrieval stack** — live knowledge synchronization, semantic corpus search, retrieval-augmented governance responses, model upgrade governance, and response traceability.
5. **Governance readiness and convergence certification** — readiness scoring, convergence gap resolution, outcome validation, GA promotion, release-bundle certification, and epoch transition proofs.
6. **Federated and community governance controls** — federation keying, cross-instance knowledge bundles, federation amendment consensus, community amendment pipelines, and anti-unilateral controls.
7. **Safety control loops for autonomous development** — pressure indices, mutation throttles, pre-admission gates, circuit breakers, rollback engines, violation remediators, and coherence oracles.

Counsel should map each family to registry entries in `PRIOR_ART_REGISTRY.json`, then determine whether any public disclosures, publication dates, or repository history affect filing windows.

## Licensing posture

ADAAD appears positioned as an open-source governance platform with separate brand controls:

- Code and documentation licensing should remain consistent with the repository's existing license files.
- Trademark and brand permissions should remain separate from copyright license grants.
- Third-party assets or models should not be added without provenance, license terms, and redistribution rights.
- Patent strategy should avoid implying that repository publication grants a patent license beyond the explicit repository license text.
- HUMAN-0 signing, ratification, release tagging, and legal filings remain non-delegatable governance actions.

## Open-core split boundary

A conservative open-core boundary should keep externally auditable trust primitives open while reserving hosted operations, enterprise integrations, and managed governance services for commercial offerings.

### Recommended open core

- Constitutional invariant definitions and validators.
- Deterministic replay and verification scripts.
- Ledger formats, proof-bundle schemas, and offline verification tools.
- Local demos and minimal governance dashboards needed to inspect evidence.
- Documentation required for independent security and prior-art review.

### Candidate commercial/managed layer

- Hosted governance observability and fleet dashboards.
- Enterprise identity, policy, and ticketing integrations.
- Managed evidence retention, notarization, and compliance exports.
- High-scale federation coordination and managed key ceremonies.
- Private model/provider routing, support tooling, and SLA-backed operations.
- Counsel-ready IP reports, disclosure packs, and customer-specific audit binders.

### Boundary invariants

- Never close-source the minimum artifacts needed to verify constitutional claims already made public.
- Never make trust depend on a hosted service when a repository-local deterministic verifier is promised.
- Never weaken HUMAN-0, fail-closed, replay, or evidence requirements to create a commercial upsell.
- Keep brand/trademark permissions independent from open-source code permissions.

## Counsel review checklist

- Confirm inventorship and ownership for each patent candidate family.
- Check public disclosure dates in `PRIOR_ART_REGISTRY.json` against filing deadlines.
- Decide which registry entries should become provisional patent exhibits.
- Run clearance searches for trademark candidates before launch collateral expands.
- Confirm whether current repository licensing includes or excludes patent grants as intended.
- Validate that open-core packaging does not contradict public trust-center claims or governance invariants.
