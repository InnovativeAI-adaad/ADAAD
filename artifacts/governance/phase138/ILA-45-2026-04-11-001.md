## Hard-Class Invariants Added

### IIG-COFIRE-0 (`runtime/innovations30/invariant_interaction_graph.py`)
Every co-fire observation appended to the graph MUST be hash-chained to its
predecessor using the canonical schema `{seq, epoch_id, inv_a, inv_b, timestamp,
prev_hash}`. The genesis entry uses `prev_hash = "0" * 64`. Any chain break is
a constitutional violation detected by `verify_chain()`.

**Enforcement:** `InvariantInteractionGraph.record_epoch_firings()` computes and
assigns `entry_hash` before any persistence write. `verify_chain()` replays the
full chain and raises `IIGChainViolation` on any mismatch.

### IIG-DETERM-0 (`runtime/innovations30/invariant_interaction_graph.py`)
Identical sequences of `record_epoch_firings()` calls MUST produce identical
`graph_digest` values regardless of runtime instance or timestamp. The digest
is a pure function of node fire-counts and edge co-fire-counts.

**Enforcement:** `_compute_graph_digest()` serialises sorted `(id, count)` tuples
via `json.dumps(sort_keys=True)` and hashes with SHA-256. No wall-clock or
random inputs enter the digest.

### IIG-PERSIST-0 (`runtime/innovations30/invariant_interaction_graph.py`)
Graph state MUST round-trip through the jsonl persistence store without loss.
A graph reloaded from disk MUST have the same `graph_digest` as the in-memory
instance that wrote it.

**Enforcement:** `_load()` reconstructs nodes, edges, and the observation list
from the jsonl store. Tests `test_iig_20` and `test_iig_21` verify digest
equality and co-fire-count preservation across reload.

### IIG-CLUSTER-0 (`runtime/innovations30/invariant_interaction_graph.py`)
`greedy_clusters()` MUST be deterministic: identical edge weights MUST produce
identical cluster assignments. The algorithm iterates invariant IDs in sorted
order and assigns greedily by strongest edge weight.

**Enforcement:** The algorithm uses `sorted(self._nodes)` as its iteration order
and pure arithmetic comparisons. No random or hash-order-dependent operations
are used. Tests `test_iig_22` and `test_iig_23` verify determinism and coverage.

### IIG-HUMAN0-0 (`runtime/innovations30/invariant_interaction_graph.py`)
Removing an invariant node from the graph (and all its edges) MUST require
`human_auth=True`. Calling `remove_node()` without this flag raises
`IIGAuthorizationViolation` with the invariant ID and gate name in the message.

**Enforcement:** `remove_node()` raises before any mutation if `human_auth` is
falsy. Tests `test_iig_25`, `test_iig_26`, `test_iig_27` verify the gate fires,
the removal succeeds with auth, and edges are cleaned up.
